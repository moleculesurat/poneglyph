# 07 — Submission requirements (exact form fields)

## Registration form (required to enter)
| Field | Type | Required |
|---|---|---|
| Name of (Organization / Startup / University) | text | ✅ |
| Designation | text | ✅ |
| City | text | ✅ |
| LinkedIn profile | url | optional |

## Round 1 — Idea Submission (the Jul 12 deadline)
| Field | Type | Required |
|---|---|---|
| Team Members — Name & Organization (if any) | textarea | ✅ |
| Brief description of the idea | textarea | ✅ |
| Proposed solution — business model / commercial potential | textarea | optional |
| Technology stack details | textarea | optional |
| Process flow / architecture | textarea | optional |
| Upload your idea deck | file | optional |
| Demo video link (max 3 minutes) | url | optional |
| GitHub repository link (if any) | url | optional |

> Only two fields are strictly required (team members + idea description), but the "optional" fields are
> the actual scoring surface. **Do all of them** — tech stack, architecture, a tight deck, and ideally a
> ≤3-min demo video + a GitHub link. An idea with a working sliver + video beats a text-only idea.

## Round 2 — Prototype Development (Jul 13 → Aug 21)
Working prototype + demo video; shortlisted teams demo to the SEBI jury (~Aug 17).

## Round 3 — Final Pitch & Awards (Sep 9–11, at GFF)
Live final pitch at Jio World Centre, Mumbai.

## Submission notes from the rules
- Original work only; no IP infringement (rule 3).
- Must specify, for PS2: the **intermediary category** + **regulatory corpus** + demonstrate on **one concrete
  regulatory scenario** (from the PS desired-outcome text).
- Comply with confidentiality / security / data-privacy requirements (rule 8).
